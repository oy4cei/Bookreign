Отдельно стоит проверить загрузку обложки из iCloud Photos и большие реальные библиотеки.

Данные первой книги также сверены со [страницей издателя](https://starylev.com.ua/knyga-malyuk-cuye-zvuk).
- В сохранённой книге появилась команда «Найти данные по ISBN». После просмотра и подтверждения она заполняет пустые поля и служебное название. Идентификатор издания, экземпляры, места, выдачи, собственное фото и личные правки сохраняются.
- Финальный `swift test --disable-sandbox`: **36 тестов прошли** (19 LibraryCore + 17 BookCatalog), 0 ошибок. Проверены точный ISBN, резервный источник после HTTP-ошибки, отмена запроса, некорректный ответ, сохранение личных правок и ISBN с префиксами `ISBN` / `ISBN-13:`. Финальная сборка для iOS Simulator успешна: версия **0.1.1 (2)**.
- XCUITest на iPhone 17 Pro / iOS 26.4.1: **3 теста прошли**, 0 ошибок и runtime warnings. Новый сценарий обновляет сохранённую карточку с ISBN, перезапускает приложение и проверяет новое название, один экземпляр и прежнюю полку «Детская».

- Резервный источник использует публичные JSON-эндпоинты сайта, поэтому его структура и доступность могут меняться. Сетевые ошибки не показываются как отсутствие книги. Полного покрытия всех украинских, русских и английских изданий эти каталоги не гарантируют.

## Enter и предпочтение украинской карточки — версия 0.1.2

- Воспроизведена ошибка: ввод ISBN с Return в поле сканера не открывал поиск. Новый XCUITest падал на ожидании карточки после ввода, поскольку у поля отсутствовал `onSubmit`.
- Enter / «Найти» теперь проверяет ISBN, сохраняет его в очередь и после закрытия сканера запускает поиск именно введённого номера. «+» сохраняет пакетное добавление в очередь. Некорректный ISBN остаётся в поле для исправления.
- ISBN-поиск открывает предпочитаемый результат для проверки перед сохранением. По умолчанию предпочитается украинская карточка; явно выбранный язык поиска имеет приоритет. Альтернативные сведения с тем же ISBN доступны в выборе «Данные книги». Переключение сохраняет собственную фотографию и заметки.
- Если Open Library находит запись на другом языке, дополнительно проверяется MEGOGO BOOKS. Результаты не получают вымышленный язык: русская карточка остаётся русской, украинская — украинской. Отказ дополнительного источника не теряет уже найденную запись, отмена запроса не превращается в успешный частичный ответ.
- Живой `CatalogClient()` для `9789667047337` вернул первой «Абетка» / uk / MEGOGO BOOKS, второй — «Azbuka» / ru / Open Library. Это расхождение данных каталогов, а не доказательство существования двух разных физических изданий с одним ISBN. Повторно проверен `9789664481974` → «Малюк чує звук» / uk.
- Swift-проверки: **46 тестов прошли** (19 LibraryCore + 27 BookCatalog), включая 10 новых проверок языкового предпочтения, несовпадающего ISBN, отказов источника и отмены запросов.
- XCUITest, iPhone 17 Pro / iOS 26.4.1: **5 сценариев прошли**, 0 ошибок и runtime warnings. Добавлены ввод ISBN с Enter без нажатия «+»/«Проверить», поиск нового ISBN при уже заполненной очереди, украинский вариант по умолчанию, ручное переключение варианта и проверка сохранения после перезапуска.
- Финальная сборка iOS Simulator успешна: **0.1.2 (3)**. Независимая проверка провайдера и UI завершена; замечание о сохранении заметок и собственного фото при смене варианта исправлено и проверено повторно.
- После последней правки повторно запущены оба новых UI-сценария: **2/2 прошли**, 0 ошибок и runtime warnings.

## Маска ввода ISBN — версия 0.1.3

- В сканере и полях редактирования постоянная подпись ISBN вынесена перед номером. Для ввода 978/979 применяется запрошенная визуальная маска `978-617-8076-41-2`; это оформление ввода, а не определение регистрационных границ издателя. Поиск и проверка контрольной цифры используют исходные цифры без дефисов.
- ISBN-10 с X, вставка номера с префиксом `ISBN-13:`, очистка, замена выделения и правка в середине номера поддерживаются. Курсор сохраняет положение относительно цифр, Backspace возле автоматически добавленного дефиса удаляет предыдущую цифру. Лишние цифры и посторонний текст не скрываются и не превращаются в другой корректный ISBN.
- Swift-проверки: **55 тестов прошли** (19 LibraryCore + 36 BookCatalog), включая 9 новых проверок маски, позиции курсора, вставки и удаления. Независимая проверка форматирования и UIKit/SwiftUI-поля не выявила P1/P2.
- UI-регрессия сначала подтверждена на сборке с чистым кэшем: ожидалась строка с дефисами, фактически поле содержало только цифры.
- После исправления свежая сборка **0.1.3 (4)** прошла **5 UI-сценариев** на iPhone 17 Pro / iOS 26.4.1, без ошибок и runtime warnings. Тест ввода проверяет дефисы, постоянную подпись ISBN и поиск по Enter; остальные сценарии проверяют украинский приоритет, очередь, сохранение, выдачу и места хранения.

## Сканирование с подтверждением и альтернативные обложки — версия 0.4.0

- «Добавить книгу» открывает сканер сразу. Распознанный ISBN и Enter используют один обработчик: проверка кода → поиск → крупная обложка, название, автор, язык и кнопка «Подтвердить». Камера убирается на время поиска и проверки. Повторные callbacks не создают дополнительные книги; запись появляется только после подтверждения.
- При отсутствии обложки доступно её добавление; при отсутствии книги в каталоге сохраняются повторный поиск и ручное заполнение. «Другие способы» открывает поиск, OCR и ручной ввод, «Сканировать несколько» — пакетную очередь. Одиночное добавление не запускает обработку старой очереди.
- Выбор альтернативной обложки доступен в новой и сохранённой карточке: каталоги, поиск картинок в интернете, прямая HTTPS-ссылка, камера и Фото. Перед применением показывается предпросмотр. Меняются только поля обложки; название, автор и язык сохраняются. Загруженное изображение хранится локально как JPEG до 1600 пикселей; интернет-импорт проверяет HTTP-ответ, тип, декодирование и лимит 12 МиБ. Ошибка или отмена не заменяет прежнюю обложку.
- `swift test --disable-sandbox`: **88 проверок прошли** (38 LibraryCore + 50 BookCatalog), без ошибок. Новые проверки покрывают ссылки, фильтрацию источников и ограничения интернет-изображений. Проверка локализаций: **325 ключей**, семь ресурсов, все ru/uk/en, **0 ошибок**.
