# Полка — первая версия

Согласованный продукт: личная библиотека бумажных книг с быстрым добавлением по ISBN, обложке или вручную. Учитываем украинские, русские и английские издания. После одобрения концепции пользователь поручил реализацию. Платформа первой версии выбрана по контексту обсуждения App Store: iPhone/iPad, SwiftUI, iOS 17+.

## Пользовательские сценарии

- Библиотека: поиск по названию, автору, ISBN; список/обложки; фильтры по месту, языку и выдаче.
- Добавление: ISBN со штрихкода, текст с фотографии обложки, поиск каталога и ручной ввод. Пользователь подтверждает найденное издание. Очередь последовательного сканирования; неизвестные ISBN сохраняются для позднего заполнения.
- Книга и экземпляры: разные переводы/издания не объединяются автоматически; повтор ISBN предлагает добавить физический экземпляр.
- Места: дом, дача, свои места; необязательная полка. Перемещение нескольких экземпляров.
- Выдача: получатель, дата, необязательный срок; возврат и история. Обычное место хранения не теряется при выдаче.
- Данные: локальная SQLite, работа библиотеки без интернета, JSON backup/restore с проверкой целостности, CSV экспорт, возможность отменить последнее изменение.
- Языки: Unicode без замены оригинальных названий; отдельный язык издания; поиск с нормализацией регистра/апострофов. Интерфейс первой версии русский.

## Границы

Онлайн-каталоги не гарантируют полноту UA/RU. Фото дает OCR-текст и поиск кандидатов, без обещания точного определения издания по рисунку. Языки OCR определяются доступностью Apple Vision на устройстве; результат редактируется. Без регистрации, облачной синхронизации и семейного доступа в первой версии. Публикация в App Store требует учетной записи владельца и отдельного шага.

## Интерфейс

Теплый светлый фон, темный текст, зеленый акцент, крупные обложки и понятные подписи. Главные разделы: книги, места, выдано. Добавление доступно с главного экрана. Поля издательства/года/заметок необязательны. Место остается видимым при добавлении серии книг.
